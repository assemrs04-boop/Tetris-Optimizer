## Tetris-optimizer

**tetris-optimizer** — это программа на языке Go, которая принимает только один аргумент — путь к текстовому файлу, содержащему список тетрамино. Программа собирает их по порядку, чтобы создать квадрат минимально возможного размера.

**Тетрамино** наиболее известны как «падающие фигуры» в компьютерной игре "Тетрис", в которой используется семь односторонних фигур (фигуры, переходящие друг в друга при поворотах, считаются одинаковыми, а при зеркальном отражении — различными).

## Требования:

Установленный Go версии 1.26.4 или новее. Вы можете скачать его с официального сайта golang.org.

### Установка:

``` bash
git clone "https://01.tomorrow-school.ai/git/assrakhimova/tetris-optimizer.git"
cd tetris-optimizer
```

### Использование:

Чтобы запустить программу, нужно передать ей один аргумент — путь к текстовому файлу с фигурами тетрамино. 

### Пример запуска:

``` bash
go run . examples/sample1.txt | cat -e
```

**Пример вывода:**

``` bash
$ 
ABBBB.$
ACCCEE$
AFFCEE$
A.FFGG$
HHHDDG$
.HDD.G$
$
```

### Валидный файл тетрамино:

В корректном файле **.txt** фигуры тетрамино должны быть представлены в следующем формате: 

Форма тетрамино обозначается символом **#**, а пустые места — символом **..**. Каждое тетрамино состоит из 4 строк по 4 символа в каждой. Фигуры тетрамино отделяются друг от друга одной пустой строкой.

## Детали реализации:

Программа состоит из следующих основных компонентов:

- **Основная программа (main.go):** Точка входа, которая считывает входной файл и координирует поиск решения. Проверяет входные данные и выводит ошибки в случае некорректного формата файла или невалидных фигур. Использует пакет **tetromino** для чтения и валидации фигур. Использует пакет **tetris-solver** для сборки тетрамино в минимальный квадрат и вывода результата. 

- **Пакет tetris-solver:** Содержит логику сборки тетрамино в квадрат. Реализует алгоритмы для поиска оптимального расположения фигур (поиск с возвратом / backtracking).

- **Пакет tetromino:** Отвечает за чтение фигур тетрамино из файла. Предоставляет функции для проверки валидности фигур.

## Запуск тестов:

Проект включает в себя **unit testing** для проверки корректности валидации тетрамино и сборки квадрата. Тесты находятся в соответствующих тестовых файлах внутри пакетов **tetromino** и **tetris-solver**.
